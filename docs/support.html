Reporting a problem

Include whatever of this you have. It usually decides how quickly something can be fixed.

  • What happened What you were doing, and what happened instead.
  • Which kind of account A personal Microsoft account or a work or school one. They behave differently, and several bugs have only appeared on one of them.
  • The exact error Rulebook deliberately shows the server's own message rather than hiding it behind "something went wrong".
  • The app version From About Rulebook in the ••• menu.

Please don't paste message contents or full email addresses into an issue. A rule's name and the shape of what failed is nearly always enough.

Signing in

Rulebook works with both kinds of Microsoft account: personal accounts (Outlook.com, Hotmail, Live) and Microsoft 365 work or school accounts.

  • The sign-in screen never appears, or fails immediately Sign-in is presented by Microsoft, not by Rulebook. If it fails before the Microsoft page appears, the app couldn't start the request at all. That's worth an issue, with the message you saw.
  • My organisation blocks it Some organisations require an administrator to approve an app before anyone can use it. That approval is theirs to give, not something the app can work around. The error names the app and the permissions, so it can be forwarded to whoever runs your organisation's Microsoft 365.
  • Removing Rulebook's access Open Manage accounts, tap the mailbox, and sign out. That removes the token from the phone. To revoke the grant itself, use account.live.com/consent/Manage for a personal Microsoft account, or myapps.microsoft.com for a work or school account.
Rules
  • A rule is marked as not working Four different things get reported that way. Rule is in error comes from Outlook itself. Folder is missing means the rule files into a folder that no longer exists; Outlook still reports that rule as healthy, which is why Rulebook checks separately. Never runs means an earlier rule stops processing before this one is reached, and moving it up fixes it. Runs on every message means the rule has no conditions, so it acts on all incoming mail; add a condition, or add the opposite as an exception.
  • "Managed by your organisation" Your administrator owns that rule. It can be read but not changed, disabled or deleted, so those controls are shown inactive rather than failing when tapped.
  • There's no "does not contain" Outlook rules have no negative match. Exclusions are expressed as exceptions instead: add the thing to the Unless section, and the rule is skipped when it matches. This is a limitation of the mail service, not of the app, and works out the same way.
  • Order matters Rules run top to bottom, and one carrying "stop processing later rules" ends evaluation for that message. If a rule seems to be ignored, check what sits above it.
  • A change didn't save Edits apply on the phone first and are then pushed to the server. If the push fails, the change is kept and the rule is marked as not saved yet, with the option to retry or discard, so a dropped connection never silently undoes your work. Deletes are the exception: a rule that looks deleted but is still filing mail is worse than an error, so a failed delete puts the rule back.
  • Changing rules needs Rulebook Pro Viewing your rules is free. Reordering, enabling or disabling, editing, creating, duplicating and deleting rules need Rulebook Pro, a one-time in-app purchase with no subscription. Restore purchase on the Rulebook Pro screen brings it back on a new phone.
Privacy

Rulebook stores no mail. It reads and writes rules on your mail server, and those rules keep running when the app is closed. There is no Rulebook account, no analytics, and no server of its own. The app talks only to Microsoft, plus Apple's App Store for the Rulebook Pro purchase.

Reading your folder list requires a permission that also grants message senders, recipients and subjects. Rulebook does not read them, but the grant is broader than the app's use of it, and why that is is worth knowing. The full privacy policy has the details.
